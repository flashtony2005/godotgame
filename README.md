# Cinderwatch · Godot 高模版

对 [kevintngo/cinderwatch](https://github.com/kevintngo/cinderwatch)（原版是单文件 HTML + three.js）的 Godot 4.4 移植**高细节版本**。
低模版在 `../cinderwatch-godot`，这个目录是「高模版」：同样的规则与数值，全部美术资产重做成程序化高细节网格。

## 跑起来

```bash
# 用 Godot 4.4+ 打开本目录，或用命令行：
/path/to/Godot --path .                 # 正常游戏
/path/to/Godot --path . -- --shots --biome=0     # 无头/窗口自测并截图到 /tmp/cw_shots
/path/to/Godot --path . -- --showcase --biome=0 --only=towers   # 只看 4 座塔（2 级）
/path/to/Godot --path . -- --showcase --biome=4 --only=skel,knight,wolf,slime,toad,wisp,golem,bat
```

`--biome=0..4` 依次是灰烬隘口 / 霜封 / 腐沼 / 焰痕荒原 / 沙海。

## 高模版做了什么

**1. 程序化建模器 `scripts/soup.gd`（对应原版 `10-gfx.js` 的 Soup）**
- 渐缩棱柱 `beam(a, b, r0, r1, sides, color, twist, ao0, ao1)`：梁、柱、骨头、炮管、枝干全靠它
- `cyl / cone / sphere / box / planks / quad`，法线 + 顶点色（sRGB→线性）+ **逐顶点 AO** 烘进同一张网格
- 一座塔 = 一张网格；炮管、水晶这种要转向的部件单独一张，省 draw call

**2. 四座塔 × 三级全部重做**（`scripts/tower.gd`，约 5400 三角面 / 4 座 2 级塔）
- 弓手塔：石鼓塔身 + 砌缝压条 + 门洞 + 四根收分立柱 + 中段横梁与交叉斜撑 + 两层甲板（承重梁 + 8 条板）+ 高低交错栏杆 + 背面梯子（踏板逐级内缩）+ 三脚火盆 + 旗 + 塔顶弓手（弓、箭筒、兜帽）
- 臼炮塔：12 棱石鼓 + 砌层 + 扶壁 + 12 段城垛 + 木板平台 + 炮车（炮身/炮箍/炮尾/炮耳）+ 三颗炮弹 + 火药桶（两道铁箍）+ 吊灯笼
- 雷塔：八棱渐缩塔身 + 扶壁 + 三层发光符文 + 铜箍 + 四爪 + 水晶簇（3 根棱柱 + 核心）+ 2/4 片环绕漂浮碎片（持续旋转/浮动）+ 点光源
- 哨所：木/石两种墙（逐块墙板 + 压条 + 窗 + 铁栏）+ 门框门轴 + 两坡瓦顶（三层瓦垄 + 屋脊）+ 旗 + 挂盾 + 火盆 + 3~6 名步兵（腿/靴/罩袍/腰带/头盔/护鼻/盾/剑/披风，剑以手为枢轴做挥击）

**3. 18 种怪 × 9 套骨架重做**（`scripts/monster.gd`，8 只 ≈ 6800 三角面）
- 人形：两段式腿（膝球）/ 两段式臂（肘球）/ 骨盆 / 胸廓 / 肋骨 / 脖子 / 头骨 + 下颌 + 眼窝 + 发光眼，按类型叠加装备：骑士板甲+盔+盾、死灵长袍+兜帽、木乃伊缠带、蛮兵獠牙、国王王冠、鼓手鼓+鼓棒
- 四足：三节躯干 + 颈 + 头 + 吻 + 耳 + 下颌 + 鬃毛 + 三节尾 + 四条两段腿
- 史莱姆：主体 + 底裙 + 内核 + 挂滴 + 高光 + 一对发光眼（呼吸式挤压）
- 虫：三节腹 + 背甲分线 + 复眼 + 螯 + 触角 + 六条两段腿（虫后额外卵囊）
- 飞行：躯干 + 头 + 耳 + 尾，翼 = 骨 + 两片薄膜（拍打动画）
- 怨灵：八棱长袍 + 8 片起伏下摆 + 头 + 兜帽 + 袖 + 发光眼
- 蟾蜍：三段身体 + 眼包 + 嘴线 + 背疣 + 前后腿（后腿三段折叠）
- 灵体：核心 + 内芯 + 拖尾光丝 + 环绕光点
- 石像：错位巨石躯干 + 肩甲 + 方头 + 眼槽 + 熔岩/冰裂纹 + 枢轴手臂 + 发光胸核

**4. 场景升级**（`scripts/world.gd`）
- 悬浮地台：36×36 顶点色地面网格（大尺度斑块 + 碎斑 + 苔色）+ 三层层理的崖壁（外凸抖动 + 崖面岩块）+ 崖顶亮边 + 底部暗板
- 植被：松（四层锥 + 外挑枝尖）、柳（三节弯干 + 六团树冠 + 9 条垂枝）、棕榈（六节弯干 + 8 片宽叶，叶片为四段带下垂）、枯木（余烬）、阔叶（粗干 + 三主枝 + 明暗两层叶簇）；每株随机朝向与 0.82~1.2 缩放
- 岩石：三球叠合 + 顶部苔盖；草簇/碎石/白骨 130 处烘成单张网格
- 建造台：12 棱石台 + 外凸毛石 + 石盘 + 四角刻痕石墩 + 可建高亮圈（发光材质）
- 照明：主光带软阴影（blur 2.2）+ 反向补光，环境光 ×1.2，glow 阈值 0.9

**5. 射程预览圈 `scripts/range_fx.gd`（交互向原版靠拢）**
- 点空地：**四种塔的射程同时画出**，各自造型/配色不同，当前要建的那座最亮，其余 42% 透明度做对比
  - 弓手塔：暖金细实线 + 外圈细线 + 8 根朝外刻度（代表单体点射视野）
  - 臼炮塔：橙红粗虚线 + 内侧一圈「最小射程 2.3」虚线死区 + 8 颗炮弹珠（射程 7.4 最远）
  - 雷塔：冰蓝细环 + 内环 + 4 道折线（链电）+ 一圈缓慢旋转的电弧刻度
  - 哨所：草绿短虚线 + 内圈 + 4 个步兵站位楔形（射程 3.4 最近）
- 悬停建造按钮/按数字键会切换高亮；选中已建的塔时按该塔当前等级只画它自己的圈（升级后半径随之变大）
- 全部是贴地叠加发光网格（unshaded + additive + 不写深度），不会挡住视线，也不会和地形 z-fighting

**6. 全屏后处理**（`shaders/post.gdshader` + `scripts/post.gd`，挂在 CanvasLayer layer 1，HUD 在 layer 10）
- 移轴模糊（画面上下两端按 vertical 9-tap 虚化，中心保持锐利）
- 红蓝横向色差、胶片颗粒、暗角、饱和度/对比/色调分级
- 4×4 Bayer 有序抖动 + 56 级量化，压掉渐变色带

## 与原版 / 低模版的差异

| 项 | 原版 three.js | 本高模版 | 低模版 |
|---|---|---|---|
| 美术 | 程序化 Soup + 后期 | 程序化 Soup + 自写后处理 | 方块/柱/球拼装 |
| 塔 | 4 类 3 级 | 4 类 3 级（部件级复刻） | 简化体块 |
| 怪 | 18 种 9 骨架 | 18 种 9 骨架（两段四肢） | 简化体块 |
| 地形 | 平面 + 装饰 | 悬浮地台 + 顶点色地皮 + 崖壁 | 平面 |
| 音频 | 有 | 无 | 无 |
| 贴图 | 无（顶点色） | 无（顶点色） | 无 |

规则、数值、道路生成、波次预算、AI 指挥官与低模版完全一致，二者可对照。

## 玩法 / 键位

自走塔防：AI 指挥官会自动建塔升级，你可以随时接管。

- 鼠标左键：选塔位建塔、点塔升级/卖塔
- `1`~`4`：弓手塔 / 臼炮塔 / 雷塔 / 哨所
- `空格`：暂停，`Tab`：AI 开关，`+`/`-`：倍速，`F`：跟随，滚轮：缩放，`Q`/`E`：切换地图

## 代码结构

```
project.godot
scenes/main.tscn        根 Node3D + game.gd
scripts/
  game.gd               主循环、波次、战斗、AI、相机、输入、展示模式
  world.gd              地图生成 + 高模场景
  tower.gd              4 塔 × 3 级程序化模型 + 步兵
  monster.gd            18 怪 × 9 骨架程序化模型
  soup.gd               程序化网格构建器（带逐顶点 AO）
  meshkit.gd            基础几何（发光材质、血条等仍在用）
  hud.gd                顶栏 / 建造菜单 / 提示
  defs.gd               塔、怪、生态区数值表
  post.gd               后处理层
shaders/post.gdshader   移轴 / 抖动 / 颗粒 / 暗角 / 调色
demo/                   实机截图（ashen / ember / 塔展示 / 怪展示）
```

## 已知限制

- 仍是**顶点色**而非贴图：近看能看到多边形与色块，想要照片级需要接 PBR 贴图与法线
- 无音频
- 后处理与 glow 依赖 GPU，软件渲染下会很慢
- 塔/怪都是运行时拼网格，首次生成有一帧开销（当前规模 < 2 万面，可忽略）
